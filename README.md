# Interview Bank Skill

[English](README.en.md) | 简体中文

`interview-bank` 是一个面向 Claude Code、Codex 等支持 Agent Skills 的 Agent 的面试题整理 Skill。它可以帮助用户从碎片化搜集的面试题目截图、已选好的文字、音视频中的语音或字幕转写稿中提取面试题，按岗位、技术领域、技术栈、公司和行业分类，合并同义问法，研究有来源支持的参考答案，并生成适合阅读和自测的两份报告，帮助用户将碎片化的面试题目积累成个人的面试题目参考库。

适用于校招、实习、秋招和社招。当前版本为 **1.12.0**。详见 [更新记录](CHANGELOG.md) 与 [GitHub Releases](https://github.com/EXIST-D/Interview-bank/releases)。

## 本次更新：1.12 增量快照、独立备份与更省的上下文

- **增量快照**：写操作只保存变化的记录（`changes.jsonl`），提交和撤销都按变更重放并校验指纹；1,000 题题库上一批答案让 runs/ 增长从约 1.9 MB 降到约 17 KB。`INTERVIEW_BANK_RUN_FORMAT=1` 可退回旧的全量快照，旧 run 仍可读、可撤销。
- **独立备份**：`backup create / verify / restore`，带哈希清单和 `.sha256` 校验；恢复只写入一个尚不存在的新目录，校验通过后才落位。
- **查询不再依赖 SQLite**：直接读取已加载的 JSONL，提交后不再重建索引；`rebuild-index` 保留为弃用的空操作。
- **低成本复核**：`answer-recheck` 用于“题目只改了措辞”的情况，沿用原答案和来源、不刷新核验日期，并记录复核依据；`search` 会给出 `answer_stale_reason`。
- **读写锁**：只读命令和 Web 页面共享锁，可同时进行；写操作仍互斥。
- **对 Agent 更友好**：`search` 默认返回题目卡片（`--detail` 取完整记录）；错误信息带稳定的 `error_type` 和下一步 `hint`；截图题目中的联系方式改为审阅项，不再让整批失败。

详见 [更新记录](CHANGELOG.md)。本地 Web 用法见 [本地 Web 说明](skills/interview-bank/references/web.md)。

## 功能范围

- **截图提取（M1）**：批量登记截图，识别字节相同的重复图片，提取题目、代码和追问，保留原文及来源，支持分批保存和续跑。
- **语义分类（M2）**：根据题意和上下文整理岗位、技术领域、技术栈、公司别名、行业、招聘类型、轮次、日期和难度，支持重新分类和纠错。
- **去重合并（M3）**：查找批内及历史题库中的候选重复题，合并相同考点的同义问法和兼容补充问法，保留原题、出现记录和合并依据。
- **分析导出（M4）**：按多条件组合筛选，统计频次与领域分布，导出 Markdown、JSON、JSONL、CSV 及 viewer JSON 数据。
- **答案研究（M5）**：搜索并阅读公开资料，核对关键结论、版本和适用条件，整理简洁参考答案及来源，保留答案历史和核验状态。

- **持续维护（1.5）**：显式升级与校验备份、人工字段保护、禁止合并规则、持久研究任务、答案覆盖检查、分批续作与更新摘要。
- **岗位/JD 专题（1.6）**：自然语言条件整理为可执行筛选，保存专题与来源快照，保留 JD 要求原文和匹配理由，输出双报告与覆盖缺口。
- **复习与模拟面试（1.7）**：保存个人自评与复习日期，生成复习队列；逐题提问、保存真实回答、针对性追问和有依据的反馈，支持中断恢复。

内置分类目录覆盖 **67 类岗位、186 个技术领域、229 个技术标签、83 个行业标签**，包括前后端、全栈、Agent、RAG、数据库、云原生、安全、嵌入式等方向。支持中文名称、常见别名、多标签和层级筛选；公司还可以记录有依据的组织类型、性质与商业模式。分类目录允许扩充，未知信息保持未确认状态。

## Agent 能力与环境要求

本 Skill 使用 Agent 的看图、推理和联网工具，不绑定某一家模型 API。Agent 负责理解材料和研究答案，Python CLI 负责数据校验、事务入库、查询与导出。

- Python **3.10 或更高版本**；核心与现成字幕解析只使用标准库。原始音视频的本地转写需在工作目录的独立环境安装可选 `faster-whisper==1.2.1`，模型缓存位于题库目录。
- Agent 能查看本地图片、读写用户授权的文件，并执行 Python 命令。
- 生成有来源的答案时，Agent 需要搜索和实际读取网页的能力。
- 通过下方 `npx` 命令安装时，需要 Node.js/npm；Python 核心工具本身不依赖 Node.js。
- 题库与输出目录应位于已安装 Skill 目录之外，并遵守用户指定的文件读写范围。

已在 Windows + Codex 环境完成实际截图整理与答案补写验证；其他宿主需提供等价工具能力。无需额外安装独立 OCR 服务、模型 SDK 或数据库服务器，但仅运行 CLI 不会自动识图、进行语义推理或联网研究。

```powershell
npx skills add EXIST-D/Interview-bank --skill interview-bank --agent codex --yes --copy
```

该命令已在 Windows 环境的隔离测试项目中验证：可发现并安装 `interview-bank`，许可证随安装保留，安装后的 Python CLI 初始化、健康检查和数据校验通过。

```powershell
npx skills add EXIST-D/Interview-bank --list
```

## 可选本地 Web 查阅与练习

可以直接告诉 Agent：

> 请用 interview-bank 打开我指定题库的本地 Web 界面，让我浏览题目和练习。

也可以在安装好 Skill 的机器上运行（将占位路径替换为实际路径）：

```text
python -B <Skill目录>/scripts/ibank.py web --bank <已有题库目录> --open
```

启动后使用返回的完整本机链接。默认自动选择空闲端口；服务只监听本机，终端中按 Ctrl+C 停止。可加 `--read-only` 禁用练习保存；只读模式仍会使用正常题库锁、缓存和事务恢复。

Web 练习采用用户自评，不自动判分或调用 AI。每题已提交记录可持久保存；当前未提交的作答和本轮位置不跨页面重载恢复。需要连续对话和 AI 反馈时，继续使用 Agent 模拟面试流程。

## 处理策略

默认流程为：**提取 → 分类 → 去重 → 提交 → 研究参考答案 → 导出两版报告**。

先筛选可复用知识题，再合并相同含义的问法；不会为了减少数量而丢掉语言、版本、场景或复杂度约束。相似度只用于寻找候选，语义合并由 Agent 结合完整题意判断。

答案优先使用官方文档、原始论文和第一方资料，核对每个子问题与来源的对应关系。通常凝练为一句直接回答和少量要点，约 100—250 字；复合题可适当延长。证据不足时明确标记待核验。“已核验来源”与“已人工审阅”是不同状态，不编造个人项目经历或实验效果。

通常按 5—10 题分批处理，先去重再研究；只复用仍适用的答案与资料。两版报告由同一份数据渲染，不需要再次生成答案。分批控制单次上下文，首次全量研究仍可能消耗较多 Token。

用户明确要求只整理题目时跳过答案研究。单独查询、导出或修改 Skill 不会触发既有全库研究；导出命令本身只读取已经提交的答案。

## 生成题库与报告

在用户指定的输出位置建立本地题库，主要结构如下。报告名称可自定义，以下使用默认示例名称：

```text
<输出题库目录>/
├── manifest.json
├── config.json
├── data/                         # 题目、出现记录、来源、公司、答案和关系
├── runs/                         # 任务、暂存、提交与审计
├── media/                        # 选择复制保留时保存的原始图片
├── cache/                        # 可重建的查询缓存
└── exports/
    ├── 面试题整理报告.md
    ├── 面试题整理报告（题目版）.md
    └── 面试题整理报告.md.details.json
```

- **参考答案版**：顶部汇总领域题数；领域使用二级标题、题目使用三级标题；每题包含参考答案、资料链接、出现次数、公司、标签和有依据的年份。
- **题目版**：与答案版题目和顺序一致，去掉答案、引用及答案进度，便于自测。
- **结构化附件**：保留内部 ID、原题、精确日期、来源关联、完整分类与答案历史，便于追溯和继续整理。

V1 的六张 JSONL 表，以及 V2 新增的 `data/state.json`，共同构成事实数据，查询直接读取，不另建数据库。修改通过暂存、校验和提交完成，保留历史与审计。相同图片重复导入不会增加频次；出现次数代表搜集记录，不代表面试人数或真实市场概率。

| 面向 Agent 的输出与维护 | 紧凑且有上限的 JSON 输出、题目卡片与分页；增量快照、`gc` 清理、独立备份与恢复、读写锁、带 `error_type` 的错误信息 |

使用时需要 Agent 能读取 Skill、访问授权文件并执行 Python；截图识别需要看图能力，来源答案需要实际联网检索。原始音视频可选择宿主转写工具或本地语音模型；云端转写由宿主按用户授权调用。具体要求见 [跨 Agent 使用协议](skills/interview-bank/references/portability.md) 与 [音视频使用说明](skills/interview-bank/references/media.md)。

已有 V1 题库可继续使用提取、分类、去重、答案研究与导出；保存专题、持久研究工作流和复习状态需要先备份并升级到 V2。加入音视频记录后需使用 1.8+。更新 Skill 不会自动迁移个人题库，也不会将旧答案标记为重新核验。

**计划开发，尚未实现：**

| 计划方向 | 待补充能力 |
|---|---|
| 视频画面题目提取 | 提取未被念出的画面文字和图示；目前仅处理视频语音，画面内容需另行截图整理 |
| 音视频处理增强 | 自动说话人分离、长录音文件内部的断点续转；目前可保留工具提供的说话人信息，并按文件恢复 |
| 公开链接与社交平台资料收集 | 从用户指定的公开链接或平台收集类似题目和答案，保留出处并核验；目前已有答案研究中的网页检索，不含专用平台抓取流程 |
| Web 管理增强 | 题目编辑、合并复核、素材导入与持久练习会话；目前已实现查阅、筛选和自评练习 |

**其他当前边界：**复习队列按需生成，没有后台提醒；精确 Token 和费用统计依赖宿主；任意历史合并的拆分恢复尚不支持，仅支持满足条件的最近操作撤销。这些能力未列入本次已实现范围。

v1.12.0 在 CI 中通过 228 项自动化测试（Windows、macOS、Linux；Python 3.10–3.13）和安装包检查，可用 `python -B -m unittest discover -s tests` 自行运行；本地 Web 已完成实际题库副本的浏览、筛选、作答自评与保存验证。截图、实际语音转写与报告流程已在 Windows 环境验证；宿主接入通过协议测试，未对所有 Agent、系统和真实云服务逐一实测。识别结果与参考答案仍需结合原文、来源和适用条件核对。

仓库包含 Skill、测试与开发工具、介绍、许可证及本页示意图。个人素材、题库、答案研究记录和本地依赖环境不随仓库发布；测试夹具均为合成数据。
