# Interview Bank Skill

[English](README.en.md) | 简体中文

`interview-bank` 是一个面向 Codex 等 Agent 的面试题整理 Skill。它可以帮助用户从碎片化搜集的面试题目截图、已选好的文字、音视频中的语音或字幕转写稿中提取面试题，按岗位、技术领域、技术栈、公司和行业分类，合并同义问法，研究有来源支持的参考答案，并生成适合阅读和自测的两份报告，帮助用户将碎片化的面试题目积累成个人的面试题目参考库。

适用于校招、实习、秋招和社招。当前版本为 **1.9.0**，本次发布包含 1.8 音视频输入与 1.9 宿主适配。详见 [v1.9.0 更新说明](https://github.com/EXIST-D/Interview-bank/releases/tag/v1.9.0)。

## 本次更新：v1.9.0

- **音视频题目整理**：支持录音、视频音轨和 SRT/VTT/TXT/JSON 字幕转写稿，保留时间戳与原文，接入分类、去重、参考答案和双报告流程。
- **转写进度恢复**：按文件保存进度，失败文件可续跑；复用已有转写，同一原文件重复导入不增加出现次数。
- **环境检测与路线选择**：检查 Python、目录写入和本地转写依赖，结合 Agent 实际可用工具，选择已有字幕、宿主转写或可选本地模型。
- **统一接入宿主转写结果**：接收不同工具返回的片段或文本，保留工具提供的时间戳和说话人信息，校验来源并支持重复提交。

完整变更与验证记录见 [v1.9.0 发布说明](https://github.com/EXIST-D/Interview-bank/releases/tag/v1.9.0)。

## 功能范围

- **截图提取（M1）**：批量登记截图，识别字节相同的重复图片，提取题目、代码和追问，保留原文及来源，支持分批保存和续跑。
- **语义分类（M2）**：根据题意和上下文整理岗位、技术领域、技术栈、公司别名、行业、招聘类型、轮次、日期和难度，支持重新分类和纠错。
- **去重合并（M3）**：查找批内及历史题库中的候选重复题，合并相同考点的同义问法和兼容补充问法，保留原题、出现记录和合并依据。
- **分析导出（M4）**：按多条件组合筛选，统计频次与领域分布，导出 Markdown、JSON、JSONL、CSV 及 viewer JSON 数据。
- **答案研究（M5）**：搜索并阅读公开资料，核对关键结论、版本和适用条件，整理简洁参考答案及来源，保留答案历史和核验状态。

- **持续维护（1.5）**：显式升级与校验备份、人工字段保护、禁止合并规则、持久研究任务、答案覆盖检查、分批续作与更新摘要。
- **岗位/JD 专题（1.6）**：自然语言条件整理为可执行筛选，保存专题与来源快照，保留 JD 要求原文和匹配理由，输出双报告与覆盖缺口。
- **复习与模拟面试（1.7）**：保存个人自评与复习日期，生成复习队列；逐题提问、保存真实回答、针对性追问和有依据的反馈，支持中断恢复。

内置分类目录覆盖 **67 类岗位、186 个技术领域、229 个技术标签、83 个行业标签**，包括前后端、全栈、Agent、RAG、数据库、云原生、安全、嵌入式等方向。支持中文名称、常见别名、多标签和层级筛选；公司还可以记录有依据的组织类型、性质与商业模式。分类目录允许扩充，未知信息保持未确认状态。

## Agent 能力与环境要求

本 Skill 使用 Agent 的看图、推理和联网工具，不绑定某一家模型 API。Agent 负责理解材料和研究答案，Python CLI 负责数据校验、事务入库、查询与导出。

- Python **3.10 或更高版本**；核心与现成字幕解析只使用标准库。原始音视频的本地转写需在工作目录的独立环境安装可选 `faster-whisper==1.2.1`，模型缓存位于题库目录。
- Agent 能查看本地图片、读写用户授权的文件，并执行 Python 命令。
- 生成有来源的答案时，Agent 需要搜索和实际读取网页的能力。
- 通过下方 `npx` 命令安装时，需要 Node.js/npm；Python 核心工具本身不依赖 Node.js。
- 题库与输出目录应位于已安装 Skill 目录之外，并遵守用户指定的文件读写范围。

已在 Windows + Codex 环境完成实际截图整理与答案补写验证；其他宿主需提供等价工具能力。无需额外安装独立 OCR 服务、模型 SDK 或数据库服务器，但仅运行 CLI 不会自动识图、进行语义推理或联网研究。

如果不熟悉安装命令，可以直接告诉你的 Agent：

> 请你为我安装这个 [https://github.com/EXIST-D/Interview-bank](https://github.com/EXIST-D/Interview-bank) Skill，并且进行简要介绍。

可在 [skills.sh 的 interview-bank 页面](https://skills.sh/exist-d/interview-bank/interview-bank) 查看本 Skill。使用 `skills` CLI 安装到当前项目的 Codex 技能目录：

```powershell
npx skills add EXIST-D/Interview-bank --skill interview-bank --agent codex --yes --copy
```

该命令已在 Windows 环境的隔离测试项目中验证：可发现并安装 `interview-bank`，许可证随安装保留，安装后的 Python CLI 初始化、健康检查和数据校验通过。

不加 `--global` 时，Codex 的项目安装目录为 `.agents/skills/interview-bank`。也可以先列出仓库可发现的 Skill：

```powershell
npx skills add EXIST-D/Interview-bank --list
```

上述参数与项目路径遵循 [skills CLI 文档](https://github.com/vercel-labs/skills)。仓库使用标准的 `skills/interview-bank/SKILL.md` 结构，入口包含 `name`、`description`、许可证及作者信息。

也可以把 `skills/interview-bank` 整个目录复制到所用 Agent 支持的技能目录，或直接让 Agent 阅读本仓库的 [SKILL.md](skills/interview-bank/SKILL.md)。若客户端没有刷新技能列表，请重新加载项目或重启客户端。

根据 [skills.sh 官方 FAQ](https://skills.sh/docs/faq)，榜单通过用户使用 CLI 安装时的匿名遥测自动收录和统计；README 或许可证不是单独的提交入口，网站展示和更新时间由平台决定。

## 使用示例

可以显式调用：

```text
使用 $interview-bank 整理这些面试题截图，自动分类和合并同义题，补充有来源的参考答案，输出带答案和纯题目两份报告。
```

也可以用自然语言描述任务：

```text
请整理这个文件夹里的面试截图，按岗位、技术领域、技术栈和公司分类。

只整理题目，不生成答案；排除自我介绍等纯个人问题。

请找出已有题库中后端 Redis 的高频题，补充官方资料支持的参考答案。

请为当前报告的前 30 题补写答案，保留题号与顺序，生成一份测试报告。

继续上次未完成的整理任务，从已保存的进度恢复，不要重复计算出现次数。

根据这份 JD，从个人题库中选出 30 道相关题，说明覆盖和缺口，生成两份专题报告。

这道题按我的题干保留，以后自动分类和合并不要覆盖。

从这个专题问我 10 题，每次一题；我回答后给出反馈，结束时总结薄弱点。

我这道题还不熟，请记录为待巩固，三天后加入复习队列。
```

如果需要一次性说明路径、范围和输出要求，可以使用下面的完整模板：

```text
使用 $interview-bank，整理“<截图输入目录>”中的全部面试题截图，
将题库和整理结果保存到“<输出题库目录>”。

输入文件仅供读取，所有新文件写入输出题库目录，不要修改已安装的 Skill。

请根据题意自动分类，合并同义题与兼容补充问法，保留原题和出处；
排除自我介绍等纯个人问题，不要猜测无法确认的公司、年份或模糊文字。

为去重后的题目搜索并读取可信资料，核对结论和适用条件，
将答案凝练为简短要点，标注“答案（参考）”并附来源。

输出带答案和纯题目两份 Markdown 报告，以及完整结构化附件。
报告按领域组织，领域内按出现次数降序编号，日期只显示年份。

请分批保存和提交，完成后说明题目数量、答案覆盖、输出文件及未解决事项。
```

## 包含内容

## 处理策略

默认流程为：**提取 → 分类 → 去重 → 提交 → 研究参考答案 → 导出两版报告**。

先筛选可复用知识题，再合并相同含义的问法；不会为了减少数量而丢掉语言、版本、场景或复杂度约束。相似度只用于寻找候选，语义合并由 Agent 结合完整题意判断。

答案优先使用官方文档、原始论文和第一方资料，核对每个子问题与来源的对应关系。通常凝练为一句直接回答和少量要点，约 100—250 字；复合题可适当延长。证据不足时明确标记待核验。“已核验来源”与“已人工审阅”是不同状态，不编造个人项目经历或实验效果。

通常按 5—10 题分批处理，先去重再研究；只复用仍适用的答案与资料。两版报告由同一份数据渲染，不需要再次生成答案。分批控制单次上下文，首次全量研究仍可能消耗较多 Token。

用户明确要求只整理题目时跳过答案研究。单独查询、导出或修改 Skill 不会触发既有全库研究；导出命令本身只读取已经提交的答案。

## 生成题库与报告

在用户指定的输出位置建立本地题库，主要结构如下。报告名称可自定义，以下使用默认示例名称：

```text
<输出题库目录>/
├── manifest.json
├── config.json
├── data/                         # 题目、出现记录、来源、公司、答案和关系
├── runs/                         # 任务、暂存、提交与审计
├── media/                        # 选择复制保留时保存的原始图片
├── cache/                        # 可重建的查询缓存
└── exports/
    ├── 面试题整理报告.md
    ├── 面试题整理报告（题目版）.md
    └── 面试题整理报告.md.details.json
```

- **参考答案版**：顶部汇总领域题数；领域使用二级标题、题目使用三级标题；每题包含参考答案、资料链接、出现次数、公司、标签和有依据的年份。
- **题目版**：与答案版题目和顺序一致，去掉答案、引用及答案进度，便于自测。
- **结构化附件**：保留内部 ID、原题、精确日期、来源关联、完整分类与答案历史，便于追溯和继续整理。

V1 的六张 JSONL 表，以及 V2 新增的 `data/state.json`，共同构成事实数据；SQLite 为可重建缓存。修改通过暂存、校验和提交完成，保留历史与审计。相同图片重复导入不会增加频次；出现次数代表搜集记录，不代表面试人数或真实市场概率。

## 当前状态与计划开发功能

当前 **v1.9.0** 已支持从素材整理、题库持续维护到岗位备考的完整流程。以下功能均已实现，由 Agent 根据用户需求调用：

| 已实现功能 | 当前可以做到 |
|---|---|
| 截图与文字提取 | 批量整理截图或已选好的题目文字，排除自我介绍等纯个人问题，保留原题和出处 |
| 音视频与字幕整理 | 转写录音和视频音轨，读取 SRT/VTT/TXT/JSON，保留可用时间戳、原文及校订记录，按文件恢复进度 |
| 自动语义分类 | 按岗位、技术领域、技术栈、公司和行业等维度分类，支持多标签、别名、层级筛选与纠错 |
| 增量入库与去重 | 向已有题库补充素材，跳过相同文件，合并同义题及兼容追问，保留出现记录与合并依据 |
| 参考答案研究 | 默认搜索并阅读可信资料，核对结论与适用条件，生成简洁的“答案（参考）”及来源；支持分批续作和过期答案复核 |
| 检索、统计与报告 | 多条件筛选、高频题与领域统计，生成带答案和纯题目两份报告及结构化附件 |
| 个人题库维护 | 校验备份、V2 升级与恢复、保护人工修改、禁止指定题目合并、保存研究进度与答案历史 |
| 岗位与 JD 专题 | 根据 JD 从已有题库选题，解释匹配理由、覆盖和缺口，保存专题并生成双报告 |
| 复习与模拟面试 | 保存自评与复习日期，按需生成复习队列；逐题提问、记录真实回答、反馈追问及中断恢复 |
| 宿主适配 | 区分环境实测与工具声明，规划转写路线，统一接入实际宿主工具的转写结果 |

使用时需要 Agent 能读取 Skill、访问授权文件并执行 Python；截图识别需要看图能力，来源答案需要实际联网检索。原始音视频可选择宿主转写工具或本地语音模型；云端转写由宿主按用户授权调用。具体要求见 [跨 Agent 使用协议](skills/interview-bank/references/portability.md) 与 [音视频使用说明](skills/interview-bank/references/media.md)。

已有 V1 题库可继续使用提取、分类、去重、答案研究与导出；保存专题、持久研究工作流和复习状态需要先备份并升级到 V2。加入音视频记录后需使用 1.8+。更新 Skill 不会自动迁移个人题库，也不会将旧答案标记为重新核验。

**计划开发，尚未实现：**

| 计划方向 | 待补充能力 |
|---|---|
| 视频画面题目提取 | 提取未被念出的画面文字和图示；目前仅处理视频语音，画面内容需另行截图整理 |
| 音视频处理增强 | 自动说话人分离、长录音文件内部的断点续转；目前可保留工具提供的说话人信息，并按文件恢复 |
| 公开链接与社交平台资料收集 | 从用户指定的公开链接或平台收集类似题目和答案，保留出处并核验；目前已有答案研究中的网页检索，不含专用平台抓取流程 |
| 本地独立 Web 管理界面 | 在浏览器中浏览、搜索、编辑和复核个人题库；目前通过 Agent 与命令行使用 |

**其他当前边界：**复习队列按需生成，没有后台提醒；精确 Token 和费用统计依赖宿主；任意历史合并的拆分恢复尚不支持，仅支持满足条件的最近操作撤销。这些能力未列入本次已实现范围。

本版通过 146 项自动化测试和独立安装包检查，已在 Windows 环境验证截图、实际语音转写与报告流程；宿主接入通过协议测试，未对所有 Agent、系统和真实云服务逐一实测。识别结果与参考答案仍需结合原文、来源和适用条件核对。

公开仓库只包含 Skill、介绍与许可证。个人素材、题库、答案研究记录、开发方案、测试工程和本地依赖环境不随仓库发布。
